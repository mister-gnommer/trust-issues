## Key things user learned
- `go vet` = static analysis (like built-in linter), short for "veterinarian"
- `go.mod` = package.json, `go.sum` = lockfile with hashes
- Go pins exact versions (no ^/~), no auto-update
- Public/private = first letter case (no `export`)
- `_` = blank identifier (deliberately ignored)
- `defer` = try/finally
- Statically-linked binary = everything in one file, no dependencies to ship
- `nil` = null (from Latin "nihil")
- `GOOS`/`GOARCH` for cross-compilation (e.g. to Windows .exe)
